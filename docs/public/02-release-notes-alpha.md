# qpyclaw Alpha Release Notes

发布日期：`2026-03-30`

当前发布级别：`Alpha / Developer Preview`

## 1. 这次发布包含什么

| 主题 | 内容 |
| --- | --- |
| 公开主目标 | 发布 `qpyclaw-node` 的首个可对外开发者预览版本 |
| 当前主模式 | `Mode B: qpyclaw-node -> Official OpenClaw Gateway` |
| 运行时形态 | 单文件 `qpyclaw_node.py` |
| 配置方式 | `config_local.py` 覆盖默认值 |
| 部署方式 | manifest 驱动的 `/usr` 恢复与同步 |
| 板级扩展 | `EC800MCNLE` 音频板板级代码与媒体同步 |

## 2. 主要亮点

### 2.1 单文件运行时

设备侧主运行时已收敛为单文件：

1. `/usr/qpyclaw_node.py`

这让 QuecPython 端更适合资源受限设备，也更方便 `/usr` 恢复和迁移。

### 2.2 官方网关接入已打通

当前已完成：

1. websocket 模式接入 Official OpenClaw Gateway
2. Gateway 侧节点可见
3. 节点命令可从 Gateway 侧成功下发

### 2.3 蜂窝自恢复已实测

当前已验证：

1. PDP 断开后可自动检测
2. 运行时可自动触发恢复
3. 重连后节点可重新回到 Gateway 在线列表

### 2.4 EC800MCNLE 板级 UI 已接通

当前 `EC800MCNLE` 音频板已打通：

1. `board_bootstrap`
2. 屏幕初始化
3. 表情图片显示
4. `qpy.ui.emotion.show`

## 6. 本次发布的重要工程约定

### 6.1 配置路径约定

当前 canonical 配置路径为：

1. `/usr/config_local.py`

兼容迁移期仍接受：

1. `/usr/app/config_local.py`

### 6.2 公开仓库配置约定

仓库内只保留：

1. 占位符 token
2. 占位符网关地址
3. 占位符签名器地址

真实配置必须保留在设备本地或未纳入版本控制的工作副本中。

### 6.3 推荐对外叙事

当前最适合的公开定位不是“量产成品”，而是：

1. 一个 QuecPython 版 OpenClaw Node 基础仓库
2. 一个适合蜂窝设备、边缘设备和板级扩展的工程底座
3. 一个从 `EC800KCNLC` 到 `EC800MCNLE` 逐步扩展的 OpenClaw 设备接入项目

## 7. 对后续版本的建议重点

Alpha 之后，优先建议推进：

1. 正式 `main.py` 启动策略
2. 语音链路接入与会话体验
3. 屏幕 UI 状态机和资源组织
4. 更清晰的权限与安全策略
5. 对外 license 与 release tag 规范化

## 8. 结论

截至 `2026-03-30`，`qpyclaw` 已具备以 Alpha 形式公开的基础：

1. 有明确的主目标
2. 有真实板卡验证
3. 有单文件运行时
4. 有标准恢复工具链
5. 有可对外阅读的 Quickstart、配置样例和发布说明

下一阶段重点不再是“能不能连上”，而是“如何把它做成一个更稳定、更有吸引力的 OpenClaw 设备接入项目”。
